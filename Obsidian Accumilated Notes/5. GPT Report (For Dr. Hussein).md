## 🧠 Patient Feedback Classification — Initial Training Report (November 2025)

### 1. Background and Objective

The project aims to automatically classify **patient complaints** using **Machine Learning (ML)** and **text analysis**.  
After a structured preprocessing phase where text data was standardized, cleaned, and encoded into a local database, our goal became clear:

> To build models capable of classifying Arabic patient feedback into **nine structured categories** across two main perspectives:
> 
> - **Patient Perspective (4 classifications):** domain, category, subcategory, classification_ar
>     
> - **Hospital Perspective (5 classifications):** severity_level, stage, harm_level, improvement_opportunity_type, status
>     

(Status was dropped since it is constant.)

The performance target was set at **≥ 0.8 accuracy**, which is considered **acceptable** for an initial healthcare NLP system, based on benchmarks in the 2025 JMIR study by Koh et al.

---

### 2. Model Design and Training

We evaluated multiple configurations:

|Model Type|Description|Target Columns|Notes|
|---|---|---|---|
|**Single-head Models**|Independent model per feature|9 total|Simpler, modular, easy to tune|
|**Multi-head Logistic Regression**|One model with multiple output heads|4 or 5 per text|Exploits inter-class correlations|
|**Stacked Models**|Meta-models built from logistic regression outputs|4–5 per text|Better for hierarchical decision layers|
|**Multi-head BERT**|End-to-end transformer model (fine-tuned locally)|4 heads|Computationally heavy but flexible|

Training was conducted on local CPU using logistic regression and BERT architectures.  
Each model used the same preprocessed data from `patient_feedback_ml.db`.

### 4. Benchmark Context

The **2025 JMIR study (Koh et al.)** tested GPT-based large models for a similar HCAT-GP classification task:

- GPT-4o achieved **≈68.8% mean concordance**
    
- GPT-4o reached **79.4% (κ = 0.62)** on domain and **69.8% (κ = 0.57)** on category
    
- **Severity, stage, and harm** were notably harder (κ ≈ 0.2–0.5)
    

👉 This supports that **our logistic regression results for domain (~81%)** are strong, and some difficulty with complex categories (subcategory, classification_ar) is expected.

### 6. Strategic Insights

1. **Focus on Feasible Labels:** Drop or merge the untrainable features (subcategory, classification_ar).
    
2. **Synthesize Data:** Use online augmentation (e.g., paraphrasing or translation-based expansion ×20).
    
3. **Enhance Data Diversity:** Seek real additional samples, especially for rare classes.
    
4. **Model Architecture:** For the next round, train:
    
    - 2 **multi-head models** — one for the patient text, one for the hospital text.
        
    - Keep a **logistic regression baseline** for each head for explainability.
        
5. **Evaluation Threshold:**
    
    - Maintain **≥0.8 accuracy** as the “go” signal for production-level readiness.
