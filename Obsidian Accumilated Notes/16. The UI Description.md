## 1️⃣ Main Pages & Purpose

|Page|Purpose / Key Features|
|---|---|
|**Home Page / Dashboard**|Summary of incidents, key metrics (total incidents, open/closed, severity breakdown). Quick stats and charts. Main landing page.|
|**Table View / View Records**|Full table with **all incidents**, filters, search, sortable columns, pagination. Optional row actions: View/Edit/Delete. Column visibility toggle.|
|**Insert Record Page**|Form to add a new incident record. Sections: Complaint/feedback text, metadata (patient, department, date, ID), classification fields (domain, category, sub-category), actions taken. Save/Cancel buttons. Optional AI/NER section.|
|**Edit Record Page**|Similar to Insert, but pre-filled. Update record, save or cancel. Same sections as Insert.|
|**Reporting Page**|Pre-built charts, graphs, summaries, KPIs. Ability to generate visual reports for management. Quick links to exports.|
|**Export Page**|User selects **columns**, filters, and date ranges for Excel/CSV export. Optional presets: “All Columns”, “Minimal Columns”, “Management Summary”. Preview of what will be exported.|

---

## 2️⃣ Layout / Navigation

- **Sidebar** (persistent, vertical):
    - Navigation links: Home, Table View, Insert Record, Edit Record, Reporting, Export.
    - Optional: User profile, settings.
- **Top Bar** (horizontal, always visible):
    
    - Page title
    - Global actions (Export, Insert quick button)
    - Search bar (optional)
- **Main Content Area**:
    - Displays the content of the selected page (table, charts, forms, export UI).


---

## 3️⃣ Table Page / View Records

**Features:**

1. Pagination – show a limited number of rows per page.
2. Sortable columns – clicking column header sorts ascending/descending.
3. Sticky headers – always visible when scrolling.
4. Filters:
    
    - Primary: Search by ID/Patient Name, Issuing Dept, Target Dept, Source.
    - Advanced (collapsible): Severity, Stage, Harm Level, Domain, Category, Sub-Category, Status, Start/End Dates.
5. Row Actions: View, Edit, Delete.
6. Column Visibility Toggle – user can show/hide columns.
7. Responsive design – table shrinks nicely on smaller screens.
    

---

## 4️⃣ Home Page / Dashboard

**Features:**

- Quick metrics:
    - Total incidents
    - Open/Closed count
    - Severity breakdown (High/Medium/Low)
- Charts:
    
    - Pie chart of severity distribution
    - Bar chart by department or stage

- Quick action buttons:
    - Add New Incident
    - Go to Table View

**Goal:** Provide a quick overview and shortcuts.

---

## 5️⃣ Insert / Edit Record Page

**Form Sections:**

1. **Complaint / Feedback Text** – textarea for raw complaint.
2. **Metadata** – date received, record ID, patient name, issuing and target department, source.
3. **Classification Fields** – domain, category, sub-category, Arabic classification (editable).
4. **Immediate / Taken Action** – what was done, follow-up.
5. **Optional AI/NER Section** – extracted patient/doctor names or keywords.
6. **Save / Cancel buttons**
    

**UX Tips:**

- Divide sections into cards or collapsible panels for readability.
- Highlight mandatory fields.
- Use tooltips for uncommon fields.
    

---

## 6️⃣ Reporting Page

**Features:**

- Filtered visual summaries (charts and KPIs).
- Pre-defined report templates: Daily, Weekly, Monthly.
- Download options: PDF/PNG.
- Optional scheduled reports via email (for future).
    

---

## 7️⃣ Export Page

**Purpose:** Give users control over what gets exported to Excel/CSV.

**Features:**

1. **Column Selection:**
    - Multi-select dropdown: show/hide columns.
    - Presets: “All Columns”, “Minimal Columns”, “Management Summary”.
2. **Filter Selection:**
    - Same filters as Table Page: department, source, severity, stage, harm level, domain, category, sub-category, status, date range.


3. **Preview Table:**
    - Show a small preview of the records that will be exported based on selected columns and filters.


4. **Export Button:**
    - Downloads Excel/CSV.
    - Optional: format for reporting (freeze headers, bold titles).

5. **Query / Logic behind export:**
    
    - Only include records that match the **active filters**.
    - Only include **selected columns**.
    - Optional: generate calculated fields (like “Days Since Feedback Received”) if required.
        

**UX Tips:**

- Drag-and-drop column ordering could be a future enhancement.
    
- Show number of rows that will be exported.
    

---

## 8️⃣ Visual Style / UX Guidelines

- **Consistency:** Same sidebar, topbar, and color palette across all pages.
    
- **Spacing & readability:** Avoid cramped tables, use cards for metrics.
    
- **Highlight actions:** Buttons for Add/Edit/Delete should be prominent.
    
- **Color coding:** Severity → red/orange/green, Status → badges (colored labels).
    
- **Responsive design:** Desktop-first, but mobile-friendly where possible.
